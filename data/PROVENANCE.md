# Synthetic data provenance

Created 2026-10-01 for this independent prototype. All 10 names, 12 documents, numeric balances, document titles, dates and qualifications were invented. They are not facts about any real issuer and not financial advice.

- `documents.json`: generated by `scripts/make_data.py`; preserves exact text and synthetic provenance per document
- `benchmark.json`: 19 author-controlled structured candidate replays produced by `scripts/make_benchmark.py`; not model responses and not a held-out dataset
- Labels were authored according to the desired narrow outcome; “unsafe-to-accept” means the candidate should not be released without rejection or review in this demonstration
- Two known failure labels intentionally differ from current implementation behavior: forecast-qualified values should abstain, and supported narrative facts should verify
- Public role description used only to choose project scope: https://eunice.ai/careers/software-ai-engineer, accessed 2026-10-01. No raw job-description copy is bundled
- No employer, applicant, customer, wallet, identity, account, resume or confidential information is included

All artifacts can be regenerated without network access or credentials. The project does not fetch filings or attestations, connect to a blockchain, or authenticate the fictional source documents.
